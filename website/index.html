For Steam Deck · SteamOS

Every game, set up right, before you press play.

DeckCompanion picks the right Proton for each game, applies community and per-game fixes, installs mods and shows you exactly what runs, all from a controller-friendly app in your Steam library.

$ curl -fsSL https://deckcompanion.renner.dev/install.sh | sh

Run it once in Desktop Mode (Konsole). No root, no system changes. Everything lives in your home folder and survives SteamOS updates.

How it works

DeckCompanion is a Steam compatibility tool plus a management app. Steam hands each game to DeckCompanion, which prepares it and hands it to the right Proton.

Install once

Run the one-line installer in Desktop Mode. Steam restarts once and DeckCompanion appears in your library.

Pick your games

Use it for all games or only the ones you choose. Your previous settings are saved and can be restored any time.

Play

Each launch applies the recipe, community fixes and mods, then starts the game with the right Proton.

Recipes are open, and you can add yours

A recipe is a small TOML file per game: the Proton build, Wine fixes, mods and settings. Recipes ship separately from the app, so a fix reaches every Deck without a new release.

Questions

Does it change my system?

No. DeckCompanion installs into your home folder only, needs no root and no system packages, and keeps working after SteamOS updates.

Can I go back to how things were?

Yes. DeckCompanion stores a snapshot of every Steam compatibility setting it changes. "Restore all" in Settings puts every game back, and uninstalling does the same.

Which Proton does a game get?

In this order: a recipe's pinned build, your own choice, GE-Proton when a community fix exists, Valve's recommendation, then the newest installed build.

Do I need Decky?

No. Decky is optional. If you use it, DeckCompanion can add a Quick Access Menu panel for the current game.

Is it free?

Yes, DeckCompanion is open source under the MIT license.
